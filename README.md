# Proyecto: Directorio de Usuarios

## Descripción
Este proyecto es una aplicación web desarrollada con Angular que implementa un directorio de usuarios, aplicando conceptos de modularidad, manejo de estado y comunicación entre componentes

## Uso de IA
Alineandome a lo pedido en la materia, se documenta el uso de herramientas de asistencia:

**Porcentaje de Uso:** Aprox. 20% (Uso de asistencia mínima).
**Herramienta Empleada:** Herramientas de autocompletado y consulta (Copilot/ChatGPT).
**Objetivo Pedagógico:** Apoyo técnico de depuración de errores tipográficos y correcciones de sintaxis puntual. Debido a contratiempos de tiempocon el formato exacto de directivas, la herramienta sirvió principalmetne para correcciones de sintaxis.
